Princípios Fundamentais

A Poética do Vazio e da Tinta

Inspirado na estética japonesa do Wabi-Sabi e nos ateliês tradicionais de aquarela e caligrafia com tinta Sumi.

間

Ma (間) · O Espaço Negativo

O espaço em branco não é ausência, mas respiração. Margens generosas, entrelinhas arejadas e composições que convidam à contemplação e foco no essencial.

墨

Sumi (墨) · Contraste Orgânico

Tons de carvão profundo em diálogo constante com a textura aconchegante do papel washi natural. Uma escala tonal rica em calor humano.

印

Hanko (印) · Ponto Focal

O carimbo vermelho laca (*Akane*) confere autoridade poética e funciona como âncora visual, pontuando os momentos de decisão e transição do usuário.

Como Utilizar o Koisei DS

Pronto para consumo via CSS nativo, Tailwind CSS ou TypeScript. 

<!-- Importe o CSS Mestre do Koisei no <head> -->
<link rel="stylesheet" href="./css/koisei-ds.css">

<!-- Inicialize o motor de revelação e tema no fim do <body> -->
<script src="./js/koisei-motion.js"></script>

<!-- Exemplo de botão e selo Hanko em HTML: -->
<span class="koisei-seal koisei-seal-md">
  <span>鯉</span>
</span>

<a href="#explore" class="koisei-btn koisei-btn-outline-light">
  Enter the water
</a>
// tailwind.config.js
module.exports = {
  presets: [require('./tokens/tailwind.config.js')],
  theme: {
    extend: {
      colors: {
        'koisei-akane': '#9c2d24',
        'koisei-washi': '#efeade',
        'koisei-sumi': '#211b15',
      }
    }
  }
}

// Uso no JSX / HTML:
<div className="bg-koisei-washi text-koisei-sumi font-display">
  <span className="flex items-center justify-center w-10 h-10 rounded-[3px] bg-[#9c2d24] text-[#f4eee3] shadow-md">
    <span className="font-['Shippori_Mincho']">水</span>
  </span>
</div>
